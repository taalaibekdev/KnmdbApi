# Пример приложения Flutter

Демонстрационное приложение с KNMDB Track and Trace:

- экран входа с обработкой ошибок (в том числе `403` с подсказкой
  обратиться к администратору департамента лекарственных средств);
- восстановление сохранённого входа при запуске через
  `FlutterSecureSessionStorage`;
- проверка лекарства по QR-коду без авторизации с наглядным вердиктом
  (легальна, просрочена, отозвана, выбыла из оборота).

## Запуск

```bash
flutter run
```

Приложение работает на **тестовом контуре**. Для боевого измените
`KnddbEnvironment.test` на `KnddbEnvironment.production` в `lib/main.dart`.
